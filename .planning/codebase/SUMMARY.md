# Codebase Map — Fajrak (FinanceTracker)

> Generated by GSD map-codebase workflow on 2026-09-10

## Overview
Fajrak is a **personal finance tracker** for Arabic-speaking users, built with Next.js 16 (App Router) + Supabase + Flutter. The web app supports full CRUD for transactions, accounts, debts, investments, budgets, savings goals, and zakat calculation. It includes an AI chat assistant (BYOK), gamification (badges/streaks/points), push notifications, and a Model Context Protocol (MCP) server for external integrations.

## Priority Improvement Areas
1. **Test coverage** — 31.91% → 80% target (dashboard pages, API routes, components)
2. **Rate limiter** — Migrate from in-memory to Redis for multi-region
3. **API documentation** — Add OpenAPI spec for webhook and MCP endpoints
4. **Offline support** — Implement service worker caching strategy
5. **Component tests** — Add isolated tests for dashboard UI components

## Key Risks
- High regression risk due to low test coverage on critical features
- In-memory rate limiter ineffective on multi-region deployments
- No migration testing infrastructure
- E2E tests depend on real Supabase account secrets
