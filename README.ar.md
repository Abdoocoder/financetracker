## ✨ نظرة عامة

**فجرك** هو منصة مالية شخصية عربية أولاً، تأخذ المستخدم بيده من أول معاملة يسجلها حتى تحقيق الاستقلال المالي الكامل.

> **رؤيتنا:** أن يكون كل إنسان على دراية كاملة بوضعه المالي، ويملك خطة واضحة للتحسين — بغض النظر عن دخله أو مستواه — حتى ينجح في تحقيق **حريته المالية**.
>
> مستلهم من قيم الإسلام في **السعي والعمل والقناعة** 🕌

**ما يميّز فجرك:**

| | فجرك | تطبيقات المالية الأخرى |
|:--|:------:|:-------------------:|
| تصميم عربي أصيل مع RTL | ✅ | ❌ |
| أدوات إسلامية (زكاة، FIRE) | ✅ | ❌ |
| خارطة رحلة الثراء | ✅ | ❌ |
| تطبيق أندرويد أصلي + PWA | ✅ | متفاوت |
| Gamification وتتبع الاستمرارية | ✅ | ❌ |
| مجاني، بدون إعلانات | ✅ | ❌ |

## 🌅 رحلة الثراء

يرافقك فجرك في 5 مراحل مالية تصاعدية:

```
🌅 وعي مالي  ──►  💳 سداد الديون  ──►  🛡️ صندوق طوارئ  ──►  📈 استثمار  ──►  👑 حرية مالية
```

كل ميزة — من التنبيهات إلى نظام الإنجازات — مصممة لدفعك للأمام في هذه الرحلة.

### 🔥 حاسبة FIRE

محاكاة الاستقلال المالي والتقاعد المبكر.

| الوضع | الوصف |
|:------|:------|
| **Lean FIRE** | هدف نمط حياة بسيط |
| **Full FIRE** | استقلالية مريحة |
| **Fat FIRE** | نمط حياة وفير |

- ملء تلقائي من البيانات الحقيقية: استثمارات + مدخرات + ديون = صافي الثروة
- محاكاة الفائدة المركبة مع تقدير سنوات الحرية المالية
- متزلجات تفاعلية: نسبة العائد، الادخار الشهري، المصاريف السنوية

### 🌙 حاسبة الزكاة

حاسبة زكاة إسلامية متكاملة وآلية.

| الميزة | الوصف |
|:-------|:------|
| ملء تلقائي | مدخرات → نقد، ديون → خصوم، استثمارات → أصول |

| تذكيرات Push | إشعارات قبل 30 و7 و0 يوم من موعد الحول |
| تعديل يدوي | سعر الذهب والفضة، النصاب |
| سجل الزكاة | تاريخ كامل للمدفوعات |

### 📈 تاريخ الصحة المالية

- رسم بياني خطي لـ 30 يوماً (Recharts على الويب، fl_chart sparkline على Flutter)
- لقطات يومية مخزنة في جدول `health_score_history`
- إحصائيات: الحد الأدنى / المتوسط / الأقصى أسفل الرسم
- Cron job يلتقط اللقطة تلقائياً الساعة 11:50 مساءً

## 📱 تطبيق الهاتف

يشارك تطبيق Flutter نفس قاعدة بيانات Supabase وFirebase مع تطبيق الويب.

| المنصة | التوزيع | الحالة |
|:------:|:-------:|:------:|
| 🤖 أندرويد | APK مباشر | [**تحميل**](https://fajrak.com/download) |
| 🤖 أندرويد | Google Play (اختبار مغلق) | ✅ تم الرفع |
| 🤖 أندرويد | PWA / TWA | ✅ متوفر |

## 🌍 الترجمة والتوطين

دعم كامل للعربية (RTL) والإنجليزية (LTR) عبر الويب والهاتف.

### الويب (Next.js)

نظام ترجمة مخصص في [`lib/i18n.tsx`](lib/i18n.tsx):

```typescript
import { useTranslation } from '@/lib/i18n';

const { t, lang } = useTranslation();

// ترجمة مفتاح
<span>{t('dashboard_title')}</span>

// حسب اللغة
<span>{lang === 'ar' ? 'مرحبا' : 'Hello'}</span>
```

لإضافة مفتاح جديد، أضفه في كلا الكائنين `en` و`ar` في [`lib/i18n.tsx`](lib/i18n.tsx):

```typescript
export const en = { your_key: 'Your text' };
export const ar = { your_key: 'النص بالعربية' };
```

### الهاتف (Flutter)

يستخدم `easy_localization` مع ملفات JSON:

```
assets/i18n/en.json   ← الإنجليزية
assets/i18n/ar.json   ← العربية
```

```dart
Text('nav_dashboard'.tr())
```

## 🔐 الأمان

| الميزة | التطبيق |
|:-------|:--------|
| **Row Level Security** | جميع جداول Supabase — المستخدم يرى بياناته فقط |
| **Auth Middleware** | `proxy.ts` يحمي جميع مسارات `/dashboard/*` |
| **CRON Secret** | API endpoints تتحقق من ترويسة `Authorization` |
| **Firebase Admin** | SDK على الخادم فقط للإشعارات الآمنة |
| **متغيرات البيئة** | جميع الأسرار في `.env.local`، غير مُودَعة في Git |
| **لا مفاتيح مُضمَّنة** | جميع بيانات الاعتماد مُزالة من الكود المصدري |

## 🚀 البدء السريع

### المتطلبات

- Node.js 18+
- مشروع [Supabase](https://supabase.com)
- مشروع [Firebase](https://firebase.google.com) للإشعارات

### الإعداد

```bash
# 1. استنساخ المشروع
git clone https://github.com/Abdoocoder/financetracker.git
cd financetracker

# 2. تثبيت الاعتمادات
npm install

# 3. إعداد البيئة
cp .env.local.example .env.local
# أضف بيانات Supabase وFirebase

# 4. تطبيق ترحيلات قاعدة البيانات
# طبّق ملفات supabase/migrations/ بالترتيب عبر Supabase SQL editor

# 5. تشغيل خادم التطوير
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000).

### متغيرات البيئة

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=

# Firebase (ويب)
NEXT_PUBLIC_FIREBASE_API_KEY=
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=
NEXT_PUBLIC_FIREBASE_PROJECT_ID=
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=
NEXT_PUBLIC_FIREBASE_APP_ID=
NEXT_PUBLIC_FIREBASE_VAPID_KEY=

# Firebase Admin (خادم)
FIREBASE_PROJECT_ID=
FIREBASE_CLIENT_EMAIL=
FIREBASE_PRIVATE_KEY=

# أمان CRON
CRON_SECRET=

# APIs خارجية
TWELVE_DATA_API_KEY=
```

### إعداد Flutter

```bash
cd mobile/fajrak_flutter

# 1. تثبيت الاعتمادات
flutter pub get

# 2. إضافة إعداد Firebase
# حمّل google-services.json من Firebase Console
# ضعه في: android/app/google-services.json

# 3. إعداد متغيرات البيئة
cp .env.example .env
# أضف بيانات Supabase وFirebase

# 4. تشغيل على الجهاز
flutter run

# 5. بناء APK للإصدار
flutter build apk --release
```
