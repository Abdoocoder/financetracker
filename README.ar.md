## ✨ نظرة عامة

**فجرك** هو أول أداة مالية عربية ذكية تمشي مع المستخدم خطوة بخطوة — من أول دينار يسجّله حتى يحقق حريته المالية.

> **رؤيتنا:** أن يكون كل إنسان على دراية كاملة بوضعه المالي، ويملك خطة واضحة للتحسين — بغض النظر عن دخله أو مستواه — حتى ينجح في تحقيق **حريته المالية**.
> 
> مستلهم من قيم الإسلام في السعي والعمل والقناعة 🕌

### رحلة الثراء

```
🌅 وعي مالي → 💳 سداد الديون → 🛡️ صندوق طوارئ → 📈 استثمار → 👑 حرية مالية
```

## 🚀 الميزات الرئيسية

### 🏠 لوحة التحكم
- ملخص شهري: الدخل، المصروف، الصافي
- **نقاط الصحة المالية** — من 0 إلى 100
- **خارطة الثراء** — 5 مراحل مالية
- **محاكي الثروة** — حساب نمو الفائض
- **تحديات الادخار** — 4 تحديات تلقائية
- **رسوم بيانية تفاعلية** مع Recharts
- إضافة سريعة مع تكرار آخر معاملة
- **تصميم عصري مميز**: واجهة مستخدم حديثة مع تدرجات لونية، زجاجية (Glassmorphism)، وخط Cairo.
- **تحسين الأداء بنسبة 94%**

### 💸 المعاملات المالية
- إضافة / تعديل / حذف المعاملات
- **معاملات متكررة** — تنفذ تلقائياً شهرياً
- معاملات قادمة ومنجزة
- بحث نصي + فلترة بالنوع والشهر
- سحب للحذف على الموبايل
- تصدير CSV

### 💳 إدارة الديون
- شريط تقدم مرئي
- خصم تلقائي شهري (CRON)
- سجل كامل للدفعات
- احتفال Confetti عند السداد الكامل
- خيار إضافة الدين المستلم كدخل

### 📊 الميزانية الذكية
- ملخص تلقائي + مستشارك الذكي
- **قاعدة 50/30/20** — توزيع تلقائي
- حدود إنفاق يدوية لكل فئة
- تتبع تقدم الميزانية
- تصور توزيع المصروفات

### 📈 الاستثمارات
- أسهم + عملات رقمية (15+ عملة)
- **تحديثات أسعار حية**
- دعم الاستثمار الحلال ✅
- محاكي الثروة التفاعلي
- ملخص المحفظة الاستثمارية

### 🔔 التنبيهات الذكية
- Firebase FCM للأندرويد
- Web Push للآيفون
- تقارير صباحية ومسائية وأسبوعية
- سياسة ذكية — إشعارات مفيدة فقط
- إدارة اشتراكات Push

### 📖 الدروس اليومية الإسلامية
- آيات قرآنية عن الرزق
- أحاديث عن الأخلاق المالية
- أدعية يومية
- مخصصة حسب مرحلتك المالية
- 25 درس علمي جديد

### 🎯 نظام الإنجازات
- نظام مستويات حسب نقاط الصحة
- شارات الإنجاز
- تتبع السلسلة اليومية
- التحديات المالية

## 🚀 البدء السريع

```bash
# 1. استنساخ المشروع
git clone https://github.com/Abdoocoder/financetracker.git
cd financetracker

# 2. تثبيت المكتبات
npm install

# 3. نسخ ملف البيئة
cp .env.local.example .env.local

# 4. تشغيل الخادم
npm run dev
```

> ⚠️ **إعداد البيئة:** اضبط ملف `.env.local` بمعلومات Supabase و Firebase قبل التشغيل.
